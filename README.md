# LiveFeedOCR
A browser-based OCR tool that extracts text in real-time from selected regions of video capture feeds.
ビデオキャプチャの映像から指定領域の文字をリアルタイムに読み取るブラウザベースのOCRツール。

## 起動

Node.js 20.19以降を用意し、リポジトリのルートで `npm install` の後 `npm run dev` を実行してください。カメラ利用にはHTTPSまたはlocalhostが必要です。配布用ファイルは `npm run build` で `dist/` に生成されます。

## OCRエンジン

OCR範囲ごとにTesseract.js、NDLOCR-Lite、PaddleOCR.jsを選べます。PaddleOCR.jsは日本語向けPP-OCRv5をブラウザー内で推論し、初回利用時にモデルとランタイムがダウンロードされます。映像画像はOCRサービスへ送信しません。処理性能・ダウンロード量は端末とネットワークに依存します。

キャプチャ画面と範囲プレビューは、それぞれ `Ctrl`＋ホイールで表示倍率を変更できます。拡大中は `Ctrl`＋左ドラッグで表示位置を移動でき、表示端から画像が外れないように制限します。キャプチャ画面では範囲枠も映像と一緒に拡大縮小・移動します。倍率100%ではキャプチャ上の従来の範囲描画操作を維持します。これらは表示だけのズームで、カメラ映像の元解像度やOCRへ渡す画素数は増えません。

PaddleOCR.js SDKはApache-2.0で公開されています。依存パッケージ、モデル、ランタイムを再配布する場合はそれぞれのライセンスと配布条件を確認してください。YomiToku Studioはブラウザー内OCR機能がありますが、再利用可能な公式ブラウザーSDKは確認できていないため、このアプリのエンジンとしては未対応です。

### ソースコード画面をOCRする場合

可能なら画像認識ではなく、元のソーステキストをコピー／エクスポートする方法が最も正確です。画像しか使えない場合は、画面をカメラで撮影するより元解像度のスクリーンショットを使い、エディターを高コントラスト・等幅フォント・大きな文字にして、構文色や行番号など不要な表示を減らします。表示ズームだけではOCR入力の画素は増えないため、入力自体を高解像度にする必要があります。

次の改善候補は、コード専用の行単位OCRです。Tesseractの単一行ページ分割（PSM 7/13）と辞書無効化を試し、固定しきい値の二値化を避けた画像と比較します。`0/O`、`1/l`、`{/[`、`.`/`,`、引用符などの誤りが重要なので、言語構文による補正は候補提示にとどめ、正解付きコード画像で文字誤り率を測って評価します。これは現時点では提案で、コード専用OCRモードは未実装です。[Tesseractの画質改善ガイド](https://github.com/tesseract-ocr/tessdoc/blob/main/ImproveQuality.md) も、入力の拡大・前処理・ページ分割の調整を推奨しています。
